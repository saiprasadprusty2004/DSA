5) Trapping Rain Water:- 

2 Methods:-
	1) Take 2 vectors of same size as heights array. PrevG and NextG. Run for loop from 1->n-1. Maximize--> PrevG[i]=max(prevG[i-1],height[i-1])
	NextG[n-i-1] = max(NextG[n-i],height[n-i]).
	Now for loop from 0->n-1. Check if min of both prevG and nextG - height[i] is > 0. If yes, then add it to the sum.
	
	2) Space Optimization:- Instead of taking 1 pointer and running it from start to end, we can start from both extremes and try to go towards the middle
	we have the max in left and max in right for now. so, we check which is the limiting height. if l is less than r, then l is limiting one, so we can 
	solve for that safely. maxl-height[l]... and so on for right.
